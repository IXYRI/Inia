# Inia

Inia is a compact, `.ini`-shaped configuration format with ordered writes,
arrays, objects, selectors, references, and explicit insertion operations.

The three specification editions are parallel and have equal authority:

- [English specification](SPEC.md)
- [繁體中文規格](SPEC.zh-Hant.md)
- [日本語仕様](SPEC.ja.md)

Supporting files:

- [Surface grammar](grammar.abnf)
- [Conformance examples](tests/)
- [0BSD license](LICENSE)

The ABNF describes the surface forms. The specifications define contextual
semantics and evaluation.
